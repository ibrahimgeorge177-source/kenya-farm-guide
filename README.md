# Kenya Farm Guide

A simple static website scaffold, ready to run locally in VS Code and later host for Google AdSense.

## What's included
- `index.html` — homepage
- `about.html` — about page
- `contact.html` — contact page (email already filled in)
- `privacy.html` — privacy policy (covers cookies, Google AdSense, analytics)
- `style.css` — site styling
- `articles/` — 3 starter articles, linked from the homepage
- `images/` — empty folder for your images

## Run it locally
1. Open this folder in VS Code (`File → Open Folder`).
2. Install the **Live Server** extension (optional but recommended).
3. Right-click `index.html` → **Open with Live Server**, or just double-click `index.html` to open it in your browser.

## Before applying for AdSense
Per the original plan:
1. Add more genuinely useful original articles (aim for a good number of solid pages, not just these 3).
2. Put the site online with a domain — GitHub Pages, Cloudflare Pages, Netlify, or Vercel all work well for a static site like this.
3. Connect the site to Google Search Console.
4. Get some real visitors / indexing.
5. Then apply for AdSense — once approved, the ad code gets added into the HTML.

## Notes
- The privacy policy is a solid starting template but isn't legal advice — review it once you know exactly which analytics/ad tools you'll run.
- Replace the placeholder domain name (`kenyafarmguide.com`) in `privacy.html` once you've picked and registered your actual domain.
